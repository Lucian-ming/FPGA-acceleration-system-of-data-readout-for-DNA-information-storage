## 1. 最终项目事实与交付边界

1. **权威交付物确立**：
   - 最终权威提交包为 `dna-readout-accelerator`（由 Vivado / Vitis 2026.1 原生从零构建，不依赖开发期任何中间产物）；
   - 固件身份标识：`FW_BUILD_ID = bfcd40dd3c435a19`；
   - 硬件目标器件：Xilinx Zynq-7000 `xc7z020clg400-2`（BKB220 开发板，板载 FT4232HL 调试桥与 RTL8211E 千兆网卡）；
   - 主频 100 MHz，时序严格收敛（Setup WNS: +0.089 ns，Hold WHS: +0.030 ns，0 failing endpoints）；
   - 逻辑资源消耗：LUT 36,731 (69.04%)，FF 38,437 (36.13%)，RAMB36 89 / RAMB18 2，DSP 6。

2. **板测验收状态**：
   - 三层判据（架构层综合征全零、系统层载荷 SHA-256 校验、诊断层逐级取证）100% PASS；
   - 42 例完整多媒体测试集（单测试用例包含 FASTQ、水印序列、期望载荷与原图）全集验证零静默错误；
   - 2 小时连续长稳压测（263 轮次循环读出）无一例超时或失败，结果已留存在 `board/run-logs/`。

3. **文档与多媒体权威版本**：
   - **设计报告**：权威可编辑底稿为 `report/design-report-2026.docx`（含手工增补的 7 篇文献与脱敏实物图）；权威交付 PDF 为 `report/design-report-2026.pdf`（Word COM 导出，全文 28 页）；

## 2. 仓库重排与归档布局映射

为满足完赛后的开箱即用与长期可复现性，仓库整体架构调整为以最终提交包为主体组织：

| 目录 | 角色与内容 | 状态 |
| :--- | :--- | :--- |
| `src/` | 包含 `hw/`、`sw/`、`clients/`、`tools/` 核心源码，全小写命名规范，去除 `_v1_0` 后缀 | 权威源码 |
| `sim/` | 包含 `rtl/`、`golden/`、`host/` 仿真与黄金向量（117 个黄金向量逐位对齐） | 权威验证 |
| `build/` | 包含 `artifact/`（最终交付固件）、`reports/`（构建留证）、`configs/`（从零复现配置） | 权威构建 |
| `board/` | 包含 `run-logs/`（32 个小写命名板测实测日志与长稳报告） | 最终实测 |
| `data/` | 包含 42 组测试数据集与基准数据（约 108 MB） | 权威数据 |
| `report/` | 包含设计报告、海报底稿、15 张插图、支撑数据与 10 个打捞工具 | 最终报告 |

| `archive/` | 本地归档（不入 Git），含提交物原件、原始留证与涉密隔离区 | 本地留存 |
