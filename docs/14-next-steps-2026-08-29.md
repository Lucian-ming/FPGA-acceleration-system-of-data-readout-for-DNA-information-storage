## 4. 下一步的两条路，以及为什么这样排

剩下的工作分两类，卡在不同的东西上：

| 路径 | 内容 | 卡在什么 | 谁能推进 |
| --- | --- | --- | --- |
| **G3** | 烧录 → 真实回传 → LDPC → 图片哈希 | **物理开发板**（需要用户接入硬件） | 只有用户 |
| **M3** | 实际 Block Design 的集成仿真 | 不卡任何东西，纯离线 | Agent 可独立完成 |

**建议：M3 先做，且现在就做，不等板子。** 理由不是「M3 比 G3 重要」——G3 才是主路径——
而是 M3 恰好覆盖了 G3 最容易翻车、且在板上最难定位的那一类错误：

- 地址译码错、地址段重叠、GP0 到四个从机的路由错；
- DMA MM2S/S2MM 与 DNA AXIS 的 `TLAST`/背压配合；
- Voter/Decoder 的 AXI4 master 突发、`WSTRB`/`WLAST`、越界访问；
- BD 里出现关键 black box 或 stub。

这些错误在板上表现为「卡死 / 数据全 0 / 随机错」，只能靠 UART 打印和 ILA 猜；
在 BD 仿真里则是明确的事务级失败。**先做 M3 相当于把板上最贵的调试时间提前买断。**
M2 已经证明三级算法链本身正确，所以剩余风险确实集中在「连接」而不是「算法」上。

若用户的板子随时可用，两条路可以并行：M3 在本机跑，G3 由用户按
`docs/12-main-handoff-2026-08-21.md` §10 的步骤上板取证。

## 5. M3 的执行顺序与判据

> **执行状态更新（2026-08-29 当日）：** M3 已按本节实施，结果见
> [`docs/15-m3-bd-simulation-2026-08-29.md`](15-m3-bd-simulation-2026-08-29.md)：
> **BD-1、BD-2 已通过；BD-3 未通过**，卡在 Vivado 2022.2 PS7 VIP 的 HP0（AFI）从机
> 读通路不返回数据。入口为 `bash tools/run_m3_bd.sh [all|bd1|bd2|bd3]`。
> 下面的原始判据保留，作为 BD-3 继续推进时的对照。


技术细节见 `docs/13-xsim-simulation-plan.md` §7。这里只固化交付形态：

### 5.1 需要新增的入口

`tools/run_m3_bd.sh`，与现有三个运行器保持同一形态：从脚本位置推导仓库根、batch 模式、
显式 PASS/FAIL、非零失败退出码、超时、`hw/build/xsim/m3/<RUN_ID>/` 归档 + `summary.txt`
记 SHA-256。**不要复用 `vivado_quick_sim.tcl`**，它是旧冒烟脚本，失败不 `$fatal`。

### 5.2 三步推进，每步单独可判

| 步骤 | 内容 | 退出判据 |
| --- | --- | --- |
| BD-1 | 由 `hw/scripts/bd.tcl` 重新生成 `top_bd`，`validate_bd_design`，`generate_target simulation`，elaborate `top_bd_wrapper` | 从干净生成目录可复现；无关键 black box；数据通路无 stub |
| BD-2 | 控制面：驱动实际 AXI-Lite 路径，写/读回三个 IP 寄存器 | 地址译码正确；AW/W 独立到达仍完成；非法地址响应符合设计；复位/启动/done/idle 顺序正确 |
| BD-3 | 数据面：DMA MM2S → DNA S_AXIS，DNA M_AXIS → DMA S2MM，Voter/Decoder master → DDR 模型 | 最小批次端到端搬运通过，且与 M2 快速用例结果一致；零延迟与带背压两种内存行为都过；越界/未对齐/错误响应必须判失败 |

### 5.3 明确要写进报告的限制

- 若最终用 AXI VIP 而非真实 PS7 模型驱动 GP0，**必须写明它不是实际 PS7**；
- BFM 序列要逐项映射到 `sw/app/echo.c` 的状态机，并列出未覆盖的代码；
- 不得声称「PS 已仿真」——SG DMA 描述符管理、`Xil_DCacheFlushRange/InvalidateRange`、
  lwIP、PHY 都没有被覆盖。

### 5.4 失败时的纪律

任何一步失败就停在该层定位，保存日志和最小复现，判断是 DUT / BD 连接 / Xilinx IP 仿真模型 /
路径 / XSim 语义问题，再做最小修复。**不得为了变绿放宽判据、屏蔽 X/Z、删断言或把
ERROR 降级成 WARNING。** 改了 RTL 就必须回跑 Icarus 11/11、XSim 6/6 和 M2 完整串联。
