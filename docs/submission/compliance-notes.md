### 1.1 当前索引的非 ASCII 统计：**0 条**

2026-10-16 按当前 Git 索引核对 **925 条**跟踪路径，按原始路径字节统计 **0 条含非 ASCII 字节**。早期计数中的七条路径来自当时仍被跟踪的旧板中文资料目录 `docs/board/zynq-eco-7010/`；该目录的资料已从仓库和 Git 跟踪范围移除，不属于当前索引。可用 `git ls-files -- docs/board/zynq-eco-7010` 核实当前没有跟踪条目。

Git 默认显示会把非 ASCII 字节写成八进制转义（例如 `\NNN`）；直接在渲染后的显示结果中搜索中文会漏计。应按原始路径字节统计，例如：

```sh
git -c core.quotepath=false ls-files -z | tr '\0' '\n' | grep -cP '[^\x00-\x7F]'
# 0
```

这个数字只说明**当前跟踪路径**的情况；指南 §3.3.5.4 对目录名和文件名的命名要求仍需结合最终交付范围逐项核对。未跟踪目录不属于此项统计范围。
