已实测的 H 紧凑结构（**可直接用，不必重推**）：
- 校验位部分（前 10800 列）是双对角累加器：第 0 行连列 {0}；第 r>0 行连列 {r-1, r}。
- 信息部分：对组 t（0..149）、组内位置 m（0..359），列为 `10800+360t+m`，
