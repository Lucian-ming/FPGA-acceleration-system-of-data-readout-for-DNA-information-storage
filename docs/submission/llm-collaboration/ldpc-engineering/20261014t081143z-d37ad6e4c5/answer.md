## 低效点与周期变化

旧版 syndrome 对信息边走 `PREP→ROM→LLR→CAPTURE`，检查边走三拍；GATHER 也串行执行 ROM、LLR 读取和捕获。两者约 **87 周期/行**。EMIT 和逐列 UPDATE 各用一拍同步读、一拍写；另外每轮还单独清零 64,800 个 `sum_mem` 项。

修正版在 GATHER 中按边流水推进 ROM→LLR→捕获，并利用同一 LLR 读取结果累计 syndrome。**每次更新后的 syndrome 仍在扫描完全部行后判定**，因此收敛时返回相同码字和轮数；未收敛时也在同一轮数边界报错。融合扫描约 **25 周期/行**。EMIT 与 UPDATE 都重叠相邻项的读写；UPDATE 读过地址 `i` 后延后一拍清零 `sum_mem[i]`，避免同址读写碰撞，只保留首次完整清零。

| 阶段对照 | 基线周期 | 修正版周期 | 净减少 |
|---|---:|---:|---:|
| 桶地址 + GATHER + 独立 syndrome，合并后对应行扫描 | 744,160,824 | 108,809,597 | 635,351,227 |
| EMIT 读写 | 158,751,626 | 86,423,431 | 72,328,195 |
| UPDATE 读写 | 50,414,400 | 25,207,589 | 25,206,811 |
| `sum_mem` 清零 | 25,207,200 | 907,200 | 24,300,000 |
| **合计** | **978,534,050** | **221,347,817** | **757,186,233** |

融合项是阶段净对照：修正版的行流水同时承担 syndrome 检查和 GATHER，不能把独立 syndrome 状态简单视为“免费删除”。周期边界与上一轮相同，排除输入装载和结果读回。

## 综合与验证边界

Vivado 2022.2 `SYNTH_IMPL=0` 综合-only OOC 通过：**598 Slice LUT、541 寄存器、41 BRAM、1 DSP**；综合后估算 **WNS +1.442 ns、WHS +0.137 ns，0 个 setup/hold 失败端点**。最差路径仍是 `sum_mem` 输出经饱和更新/解码逻辑到 `decoded_mem` 写入，11 级逻辑、5 个 CARRY4；没有出现新的 ROM/地址生成路径成为主关键路径。该 WNS 是**综合后估算，不是布线后数据**，不能替代整机 impl 时序验收。[timing.rpt](<仓库根目录>/logs/vivado/ldpc-speed1-fix1/reports/synth_ldpc_decoder_p1_ldpc_speed1_fix1/timing.rpt) 和 [util.rpt](<仓库根目录>/logs/vivado/ldpc-speed1-fix1/reports/synth_ldpc_decoder_p1_ldpc_speed1_fix1/util.rpt) 留有报告。
