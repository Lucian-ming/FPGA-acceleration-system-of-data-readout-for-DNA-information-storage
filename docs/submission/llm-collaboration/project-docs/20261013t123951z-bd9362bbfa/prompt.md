### 要查的问题类型（不限于此）
1. **死代码 / 零引用**：定义了没人用的函数、常量、文件；`AGENTS.md` 明确要求"零引用文件不得留在 `hdl/`"。
2. **重复实现**：同一功能多份实现（历史上的同名模块问题）；拷贝粘贴出来的分支。
3. **魔法数字**：硬编码的几何/阈值/地址，且**没有**集中定义或注释说明来源。
4. **可读性**：命名看不出用途、函数过长、嵌套过深、注释与代码矛盾、注释掉的死代码大段滞留。
5. **可扩展性**：几何（READ_BPS/NUM_LC/STRIDE/REF_LEN/BATCH）是否真的参数化、还是有地方写死；
   新增一个 profile/payload 要改几处；有没有把"实验默认值"混进生产路径的风险。
6. **本仓库特有的坑**（`AGENTS.md` 明文记过，请核实是否还存在）：
   - 注释或文档里**用行号指代码位置**（应改用标识符）；
   - 同步 FIFO 读延迟按注释数而不是按实现数；
   - 控制寄存器写序列在 TB 里没按固件原样回放；
   - `MAX_WATERMARK_SIZE`/`TOTAL_READS`/`NUM_LC`/`REF_LEN` 被当成互相独立的常量
     （它们之间有约束 `NUM_LC*STRIDE = L - READ_BPS`、`REF_LEN = STRIDE + READ_BPS`）。
7. **错误处理**：静默失败、返回码被忽略、`catch`/`|| true` 吞掉错误。
