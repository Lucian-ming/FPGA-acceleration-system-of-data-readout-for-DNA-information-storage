## 2. 结构必需与实现开销

| 部分 | 结论与证据 |
|---|---|
| 水印 `gen_wm_bank` | **存储内容没有复制 K 份。** RTL 按扁平地址的 `addr mod K` 分 bank，写入只命中对应 bank。Vivado 内存映射日志显示 K2 两个 `23K×2` bank、每 bank 2 个 RAMB36；K4 四个 `11K×2` bank、每 bank 1 个 RAMB36。水印总计均为 **4 个 RAMB36**。 |
| `plane_lo/plane_hi` | **数据按 `addr mod K` 分 bank，没有把每个地址写入所有 bank。**但 BRAM 物理映射有明显分 bank成本：K2 是 4 个 `75×64` 数组、每数组 2 个 RAMB36，共 8；K4 是 8 个 `38×64` 数组、每数组 2 个 RAMB36，共 16。它解释了 K4 相对 K2 多出的 8 个 RAMB36，**不解释 LUT +12,634**。 |
| `gen_match` | RTL 的匹配结果数为 `P_WAYS×BATCH×K`：K2 为 2,048 路，K4 为 4,096 路，结构上正好翻倍。**单独匹配矩阵的 LUT 增长未能从报告测出**；全设计 LUT 并未呈现线性增长。 |
| `score` 计分 | 每个候选位置/记录仍只有一个 `score[p][t]` 累加器，K 路匹配先汇成 `score_inc` 再更新；没有复制整组累加器。K 增大带来的局部 K 路求和逻辑是结构成本。 |
| `gen_tree` 选优树 | `P_WAYS=16`、`BATCH=64`、`PIPE_TREE=1` 不随 K 改变，RTL 上树结构不复制。K4 与 K2 总 FF 分别为 26,499 和 26,509，也没有显示树被整体复制。树自身 LUT 的微小映射变化未测。 |
| `/K`、`%K` 地址表达式 | K 是编译期常量 2 或 4，对无符号地址的除模可化为移位和取低位；报告中没有证据表明生成了通用除法器。真正值得查的是其周边地址表达式：RTL 在 bank/lane 路径中多处计算 `lc_idx * REF_LEN`（`REF_LEN=957`）。K4 的 Vivado 路由后最差路径从 `lc_idx_reg` 到 DSP，数据路径 8.154 ns、11 个逻辑级；DSP 映射日志也列出了乘以 `0x3bd`（957）的运算。这使地址算术成为**有证据支持的高优先级嫌疑项**，但还不能把 12,634 LUT 归因给它。 |

## 3. K4 是否能做便宜

可以做有针对性的优化探针，但**现有证据不足以给出可信的 LUT 节省预测**。优先尝试：

- 将 `lc_idx * REF_LEN`、延迟 tag 的行基址乘法移出 bank/lane generate，共用或预计算行基址；窄化地址中间量到实际所需位宽。
- 针对 K=2/4 显式用低位计算 bank 号。当前 `REF_LEN=957` 对 4 取模为 1，因此 `(lc_idx*957 + offset) mod 4` 可用 `lc_idx` 与 `offset` 的低两位计算。
- 检查 `wm_sym_q[source_bank]` 等动态 bank 选择能否改成明确的 lane/银行旋转连接，减少宽地址参与选择的组合逻辑。

**外推预算：**若 K4 回到 K1→K2 的 LUT 增长斜率，约为 31,080 LUT，相对当前可解释的异常差额约 10,262 LUT。可把“至少节省 5,342 LUT、降到 36,000 LUT 以下”设为第一轮优化门槛；这是验收目标，**不是已经证实能达到的节省量**。实际节省需重新综合和布线确认。

共享或集中计算可能增加高扇出，导致布线时序变差；把基址寄存/流水化可能增加寄存器或预充延迟。K4 当前 OOC WNS 只有 +0.185 ns，这些改法都要同时看布线后 WNS。

## 4. K4 是否值得整机集成

**当前 K4 不建议直接投入整机集成；先处理并验证地址路径的实现开销。**

K4 的 41,342 LUT 加非 Stage1 部分约 7,120 LUT，整机推算约 **48,462 LUT（91.1%）**，只剩约 4,738 LUT。现有整机 33,987 LUT、63.89% 时 WNS 已为 +0.617 ns；项目记录也指出 OOC WNS 可能显著乐观。K4 OOC 虽无失败端点，WNS 仅 +0.185 ns；报告还显示关键路径落在 `lc_idx` 至 DSP。它不足以证明整机布线能守住 100 MHz。

## 5. 改进版 K4 的可证伪验收判据

建议把以下条件全部作为通过门槛：

1. Stage1 K4 OOC、100 MHz、布线后 LUT **≤36,000**，WNS≥0、TNS=0、失败端点=0。
