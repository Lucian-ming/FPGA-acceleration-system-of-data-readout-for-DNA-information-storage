## 1. 块内提前终止判据

令 \(k=d+1\) 为已比较的碱基数（\(d=0\ldots149\)），剩余 \(r=150-k=149-d\)。候选位置 \(p\) 的最终分上界为：

\[
U_p=s_p(k)+r
\]

当前领先位置 \(w\) 是分数最高且并列时位置最低的候选。用这组上界证明它已是最终赢家，必须满足：

- 对每个 \(p<w\)：\(U_p<s_w(k)\)。若上界相等，较低位置仍可能追平并按规则胜出。
- 对每个 \(p>w\)：\(U_p\le s_w(k)\)。较高位置即使追平也不会取代 \(w\)。

对一个含 64 条读段的位置块，只有 **64 条读段都满足判据**，共享的 `S_RUN` 才能按这个条件提前结束；块的判定拍数是 64 条各自判定拍数的最大值。

但这只确定了赢家位置，**还没有得到赢家的最终分数**。Stage1 结果包含分数，Voter 还用它与 `score_min` 比较；若只锁定位置就退出，分数可能不精确，不能保持 Stage1 结果不变。若要跳过整个块，一个可证明精确的条件是：对每条记录的所有有效候选，都有 \(U_p\le best\_sc[t]\)。因为当前块的位置晚于已扫描位置，即使打平也不会替换更早的赢家。这个“已有全局最优值剪枝”不同于单纯确定块内赢家。

统计使用逐符号整数相等计分、前缀累加和低位置优先的 `argmax`，对应 RTL 的精确分数与并列规则，不使用 FFT 浮点结果。

| 指标 | 实测结果 |

| 单条记录的赢家位置首次可证明拍数 | 均值 147.83/150；中位 148；P90、P99 均为 150 |

## 3. 其它精确算法方向

| 方向 | 是否精确 | 收益与代价 |
| --- | --- | --- |
| 按已有全局最好分剪枝 | **可精确**。块内所有记录、所有有效位置的上界都不超过各自已有 `best_sc` 时，可以跳过该块；相等可剪，因为之前扫描的位置更低。 | 可减少起点计算，但只在已建立足够好的 incumbent 后生效；全量收益未测。需每拍比较至多 64×16 个上界并归约，扇出、LUT 和时序代价未测。 |
| coarse-to-fine | 只抽稀起点后局部精搜，**不保证精确**；全局最优可能落在漏搜处。 | 若对每个漏搜区间再用可证明上界认证，才精确；实质是分支界定，最坏会退化为全搜，并增加首轮与归约开销。 |
| 分块投票或多数选位置 | 一般**会改变 argmax**。 | 只有每块先算精确最高分、并保留低位置 tie，再做全局最大值归约才精确；当前层级选优已是这种形式。 |
| 利用错误率、覆盖度做界 | 平均错误率或覆盖度是统计量，**不是逐条硬界**，不能据此精确排除候选。 | 可研究确定性的符号计数/后缀分数上界；这类界忽略符号顺序，可能偏松，硬件成本与实际剪枝率均未验证。 |

## 4. 与每拍 K 个碱基并行比较

**K 路仍是当前更值得验证的 Stage1 方向。** 上述赢家锁定判据在实测样本中没有减少任何一个 64 条位置块的 `S_RUN` 周期；而 K 路有明确的静态周期收益：

| 每拍碱基数 | 每块周期 | 相对 176 拍 |
| ---: | ---: | ---: |
| K=1 | 176 | 1.00× |
| K=2 | 101 | 1.74× |
| K=4 | 64 | 2.75× |

这些是静态周期推导，不是功能或板测结果。[多碱基 OOC 探针记录](<<仓库根目录>/docs/benchmarks/stage1-multibase-ooc-probe.md>) 中 K=2/K=4 的资源和时序仍待测；P16 当前 WNS 约 +0.617 ns，K=4 的 40k～48k LUT 也只是估计。代价是增加并行比较、读存储分 bank、资源和时序风险。

若沿用 PL 约 8.2 s、PS 约 1.1 s 的当前分解，并假设 PL 周期按 K 比例缩放，`t_result` 可外推为 K=2 约 5.8 s、K=4 约 4.1 s。**这是模型外推，不能当成构建或上板结果。**

## 5. 结论与交付

赢家上界判据在数学上能精确确定块内 `argmax`，但在本次真实样本里，64 条记录合取后没有提前一拍；即使某条记录提前锁定，精确输出分数仍须计算。可精确缩短工作的方向是基于已有全局最优分的上界剪枝，但目前未测收益。若目标是缩短整轮时间，K=2/K=4 的周期收益明显更大，应先做 OOC 资源、时序与功能验证；当前资料不足以宣称它们已实现收益。
