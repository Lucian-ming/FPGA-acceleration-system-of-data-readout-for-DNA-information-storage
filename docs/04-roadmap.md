# 04 · 总体路线图

## 当前阶段

G3、SE150/SE250 全量板级闭环已完成。项目进入“性能可证明、数据可泛化、上位机可交付”阶段。

## 阶段 S0：证据与基线

- 固定当前 bitstream/ELF/BOOT.bin 哈希；
- 建立 CPU 单核、多核和 FPGA 同输入基线；
- 压测增加失败分类与阶段级计时；
- 不修改真实数据集。

**出口：** 每次运行有输入哈希、分段时间、最终哈希和失败类别。

## 阶段 S1：时间优化

1. 上位机流式读取、缓冲复用和传输重叠；
2. Stage1 64×4 展开；
3. Stage1 64×8/128×4 资源评估；
4. DMA 双缓冲和 DDR 往返削减；
5. 每一版都进行 XSim、综合、整机实现和板端 G3。

**出口：** 在同输入、同正确性判据下，端到端耗时有可重复下降。

## 阶段 S2：方向 A 通用参数化

- 多 payload 重新编码和 manifest；
- 运行时读长/水印/几何配置；
- 错误几何在任务开始前拒绝；
- 至少 5 个 payload 通过最终哈希和中间级别检查。

## 阶段 S3：方向 B 错误鲁棒性

- substitution/insertion/deletion 注入；
- 0.5×/1×/2× 覆盖度；
- `score_min` 扫描；
- 输出恢复成功率、原始误码、LDPC 迭代和耗时边界曲线。

## 阶段 S4：上位机交付

- Python 参考实现、C LDPC、协议会话、GUI 模块化；
- 超时、断连、错误配置可诊断；
- 结果流式保存，报告自动生成；
- 全量数据、长稳和错误矩阵回归。

## 阶段 S5：竞赛冻结

冻结器件、制品、工具版本、演示数据、演示脚本和答辩数字。未实测的性能、功耗和通用性只能写成目标。
