## 保留的非 CPU 内容（供历史引用）

CPU 测量数据已删除；以下 FPGA 侧内容仍被其它文档引用，保留在此：

- 板端 2-way 100 MHz 拟合模型：`T = 4.25 s + 0.58 ms × N_records`。
  后续实测重拟合为 5.089 s（仅 N≥4,096 的点）与全档 5.284 s；
  原常数项解释（lwIP 握手、CAPS/CONFIG、DMA、Voter 初始化）在数量级上不成立。
- 原 §3.3 的分解 `0.58 ms = 0.470 ms(Stage1) + 0.11 ms(DMA)` 已被板端斜率反解推翻：
  实测 Stage1 只占 37.1%，其余 62.9% 为 DMA/Voter/poll/回写。
- 上述只保留 FPGA 模型与更正，不代表任何 CPU 对照结论。
