## 3. 测量结果

| 阶段 | 耗时（s） |
| --- | ---: |
| 滑动相关 | 40.48 |
| 大数合并 | 0.09 |
| LDPC 译码 | 0.50 |
| **墙钟总计** | **41.07** |
| 峰值内存 | 30.29 MB |

- 输入规模：**675 条读段**；
- 滑动相关吞吐：**平均 16.6 条/s**（按 675 / 40.48 计为 16.67；按墙钟 41.07 计为 16.43）；
- 记录中未给出重复次数、方差、线程数或并行配置。

## 4. 使用口径

1. **这是项目唯一的 CPU 基线设备**。任何对外材料提到 CPU 对照，都必须写明
   「Xeon Gold 5220R ×48 @2.20 GHz、675 条读段、41.07 s」。
2. **不得与 FPGA 的 `t_result` 直接相除后称为"加速比"**：
   本基线包含滑动相关 + 大数合并 + LDPC 的完整墙钟，而 FPGA 的 `t_result`
   不含上传；输入规模也不同。相除只能得到指示性倍率。
3. **不得与优化 C 的历史数字混用**。同一算法在做过位级优化的 C 上可快两个数量级；
   本基线代表的是项目参考实现，不代表最优 CPU 实现。
4. 原始记录只有一次测量，没有重复与误差统计；引用时应注明这一边界。
