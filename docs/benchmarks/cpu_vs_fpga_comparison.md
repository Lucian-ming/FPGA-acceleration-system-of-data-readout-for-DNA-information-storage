## 2. 审计结论

- 表内 SE150 的 0.470 ms 大于单核 C 的 0.335 ms，连这张混合表本身都不支持“反超”。
- FPGA 2-way 是 `fpga_base_ms / 2.0`，没有读取对应板测日志；48 us/条缺少同边界来源。
- 功耗全部是估算/常量，不能称“物理实测”，据此计算的能效倍数全部撤回。
- CPU 多核数字可作待复测线索，仍需输入、CPU环境、原始输出一致性与记录单位核验。
- 生成器仍含旧文案；W1-A 修复前不得把再次生成的报告当权威摘要。
