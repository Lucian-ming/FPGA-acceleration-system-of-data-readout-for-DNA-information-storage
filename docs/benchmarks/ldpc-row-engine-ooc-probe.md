# 片上 LDPC：p=1 行引擎 OOC 探针（2026-10-14）

这是[架构决定](../reference/ldpc-architecture-decision-2026-10-14.md) §6 那一步的执行结果：
在写完整译码器**之前**，先用一个 RTL 片段做 OOC 综合+布局布线，看 100 MHz 能不能收、资源占多少。
**结论：这个数据通路收得住，余量比整机宽。**

- 被测对象：`hw/experimental/ldpc_row_engine_probe.v`（`ldpc_h_addr_gen` + `ldpc_row_engine_probe`）
- 器件：`xc7z020clg400-2`；时钟约束 **100 MHz**（周期 10 ns）
- 流程：`docs/submission/skill/fpga-timing-probe/ooc_probe.tcl`，`SYNTH_IMPL=1`（**含布局布线**）
- 命令与留证：`logs/vivado/ldpc-probe-impl.log`；报告 `logs/vivado/ldpc-probe/synth_ldpc_row_engine_probe_ldpc_row_engine/{util.rpt,timing.rpt}`（`logs/` 忽略区，文件保留）

## 1. 结果（**布线后**）

| 项 | 值 |
| --- | ---: |
| **WNS** | **+0.939 ns** |
| **WHS** | **+0.073 ns** |
| 约束 | **All user specified timing constraints are met** |
| Slice LUTs | 457（Logic 441 / Memory 16） |
| Slice Registers | 234 |
| **Block RAM Tile** | **32.5**（RAMB36E1 ×32 + RAMB18E1 ×1），占器件 140 的 23.21% |
| DSPs | 0 |

（作为对照：综合后 WNS 是 **+0.601 ns**，布线后 **+0.939 ns**——本次布线后反而更松。
项目另一处实测是同模块综合后 +2.197 ns、整机布线后只剩约 +0.2 ns，**所以综合后的数字一律不能当结论，本文只报布线后**。）

## 2. 它验证了什么

1. **这类数据通路在 100 MHz 能收住**，且余量（+0.939 ns）**明显宽于 K=2 整机的 +0.313 ns**。
   架构决定文 §5 把「时序闭合」列为最可能失败的一关，**本探针没有推翻它，但表明核心通路本身不是瓶颈**。
2. **两块大存储器的真实代价是 32.5 块 BRAM36**（`llr_mem[64800]×6` + `acc_mem[64800]×10` + 紧凑表 ROM）。
   这比架构决定文 §3 表里「LLR 16 + 累加器 32 = 48」的静态估算**乐观**——静态估算偏保守。
3. 饱和加法、行缓存、min1/min2 与符号积、BRAM 读改写这条链被真综合并布线过，不是纸面推演。

## 3. ⚠️ 它**没有**验证什么（引用时必须一起说）

1. **这是片段，不是译码器。** 资源数是**这个片段**的，**不是完整译码器的**。
   完整设计还要加：syndrome 计算、H 邻接的完整访问、顶层 FSM/控制、AXI 接口、以及架构决定文 §3 里那 32 块**可选片上 permutation**。
2. **OOC 的布线后余量不等于整机余量。** OOC 没有整机的拥塞、时钟不确定性与跨模块路径。
3. **地址生成器是扫描式占位实现**（逐个扫 600 个基地址再按 `(r−x) mod 30 == 0` 筛选），
   **它的延迟不具代表性**——真实设计应当用转置表直接生成，否则每行要多花数百拍。
   探针里 ROM 的内容也是**仿射占位**（`(i*137+593) mod 10800`），**不是真实 `B_t`**，仅为避免被综合折叠成常数。
4. **功能未验证**：没有 testbench、没有对软件黄金的比对。本探针只回答「能不能综合、装不装得下、时序收不收」。
5. 未跑 XSim、未碰板卡、未做整机 route。

## 4. 下一步

按架构决定文 §6 与交接文 §5.3(2)：**可以进入 L4（译码器 RTL 原型 + 对软件黄金验证）**。
判据仍是那三条（功能正确 / 资源与时序可行 / **板端判据 SHA 不变**），且**加译码器后必须复测 K=2 的板端数字，回退则停**。

**仍然待定、且可能改变结论的**：完整译码器的 LUT/BRAM 总量（本探针只给了片段数）、
整机布线下这条通路还剩多少余量、以及 §3 列出的那些未计入的部件。
