## 2. 结果

**墙钟 8.005 h（28,817.1 s，目标 8.0 h），1750 轮，通过 1750 轮，失败 0 轮。长稳结论：PASS。**

| 指标 | 值 |
| --- | --- |
| 墙钟 | **28,817.1 s = 8.005 h**（≥ 8 h） |
| 轮次 | **1750** |
| 通过（verdict=PASS **且** 判据 SHA 命中） | **1750** |
| 失败/异常轮 | **0** |
| 板端结果耗时 `result_s` | 中位 **4.92 s**，min 4.67 / max 5.32 |
| 畸变包恢复 | **175 次探针 × 10 用例 = 1750 次注入，`failure_class` 全为 `pass`（1750/1750）** |

10 个注入用例：正常 CAPS 握手（对照组）、半截包头、坏 magic、未定义包类型、
超长声明长度、截断 payload、CAPS 后 RST 断开、静默占用后关闭、未关连接再连第二条、
连灌 32 个垃圾包头。

⇒ 长稳同时覆盖了「**连续正确**」与「**被异常连接打扰后仍正确**」两件事。

## 3. 边界（不得外推）

- **`hardware_cycles` 与 `power_w` 恒为 `null`**：本次无外部 UART 周期采集、**无功率计**。
  TSV 里的 `result_s` 是**客户端打印值**，**不得反推周期或功耗**。
- 全程 `--skip-dump`，**不构成逐级取证证据**；四级取证另有专门留证。
- **8 h ≠ 无限**：不证明跨上电、跨温度/电压的稳定性；**不覆盖冷启动**（QSPI/SD 仍未测）。
- 判据口径：每轮按 `--score-min 67`（出厂门限）比较**板端码字载荷 SHA**；
  架构判据（syndrome 全零）每轮同样判定。**两者都过才算该轮 PASS**（三层判据）。
- 本长稳只覆盖**一个载荷**（R0.83 SE150 全量输入）的重复正确性；
  **泛化**由多载荷回归（6/7）与 C2 的 v2 42 例另行覆盖。
- 2 h 那一档是在**另一份包**（`bkb220-p16-enet0-software-20261012T144141Z`）上跑的，
  **两档不能直接相减比性能**；本文的 8 h 是 2026-10-16 期间连续一次上电、不复位不重烧。
