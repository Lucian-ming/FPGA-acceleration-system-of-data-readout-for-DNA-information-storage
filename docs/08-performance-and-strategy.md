## 2. 旧分析的适用边界

P12前的“Stage1只占37.1%、其余62.9%主导”包含lwIP poll空等。P12/P13后全量斜率已接近P4 Stage1理论周期，继续套旧Amdahl上限会误导换7020决策。旧7010 LUT接近上限不能封死7020的16路。旧定量推导、失败实验在归档保留，最新03/本表优先。

Voter/Decoder已有周期计数，历史4096记录中两级执行约29.6ms/0.02ms；未经新测量不优先重做这两级微架构。多次TX_STREAM压缩尝试失败、精确种子索引在本任务最长匹配太短且被证伪，相关负结果在benchmarks/归档，不能重复作为优先方案。

## 3. 本轮优化与测量顺序

首先让对应新板P4完整闭环，再比较同板P16；算法/协议/方向/阈值/100MHz一致。六档128/512/2048/8192/32768/full各≥3次，记录源读段与正反向补帧记录数、中位数/离散、截距/斜率及失败；相同输入SHA、独立P4/P16完整制品SHA、工具版本和软件源码必须可追溯。

明确t_result是POST至8100B收齐、不含上传和LDPC；整轮包含处理/上传/结果/LDPC/图片SHA、不含下载/DDR取证/轮间settle。模块cycle、板端结果耗时和整轮耗时分别报告，不互换。硬件计数取实际寄存器/UART，未测值null。

全量必须LDPC和图片SHA通过，小规模覆盖不足如实标明；失败不能藏在fit之外而不报告。CPU对照用优化C单核/多核，方向规则、输入、输出和线程清楚；同片ARM基准会复位整板，先审计新板适配并安排板卡独占。

## 4. 项目定位与后续边界

可以说明复杂读出系统在PS/PL/PC之间闭环、真实接口和可鉴别判据、指定数据/profile下的正确性，以及带完整口径的实测收益。任意payload/任意错误率、工业稳定、百倍通用加速、低功耗优势均需独立证据。

泛化与sub/ins/del、覆盖度和阈值按06复核；FAR是累加器污染度，不是失败率。功耗需实际仪器与同口径CPU任务能耗，缺仪器则门禁未关闭。算法重写、SE250迁移、软信息LDPC等保留后续任务池，不扩张本轮SE150/P16迁移。
