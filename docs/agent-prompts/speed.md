## 2. 已经测出来的东西（**不要重复测量，更不要重复被证伪的方向**）

### 2.1 整轮墙钟 13.272 s 的分解（全量档，3 次中位）

| 分段 | 耗时 | 占比 |
| --- | ---: | ---: |
| 水印下发 | 0.009 s | 0.1% |
| **读段上传** | **3.916 s** | **29.5%** |
| **板端处理** | **8.682 s** | **65.4%** |
| 上位机 LDPC | 0.653 s | 4.9% |
| 其他 | 0.012 s | 0.1% |

**上传完全串行排在处理之前**，是一条**独立于 PL 的优化面**；上位机 LDPC 与下一轮**无重叠**。

### 2.2 板端 8.682 s 的 PL / PS 分解（**推导值**）

`PL 7.77 s (87.8%) + PS 1.08 s (12.2%)`，由 P4/P16 两档实测斜率与 Stage1 模块周期比 3.272× 联立解出。
→ **PS 侧每条记录仅 0.0064 ms；把 PS 侧全部清零也只到 7.77 s。**
→ 自检：RTL 模型 `2550 块/记录 × 176 拍/块 ÷ 64 记录 = 7012 拍/记录`，与实测 7500 拍/记录差 6.5%，
   **说明 Stage1 几乎一直满负荷，没有成片可回收的空闲。**
⚠️ 这是**推导**（前提："P4 与 P16 只差 Stage1 周期数"），**不是直接测量**，引用时必须说明。

### 2.3 状态级（无睡眠下，全量）

`TX_STREAM` 5892 ms / `VOTER_WAIT` 602 ms / 其余状态合计约 387 ms / `[waiting]` 2362 ms。
`TX_STREAM` 一步内含：回收 RX BD → 按 free 裁剪提交 → 低水位恢复（最多 5 次 `usleep(50)`）→ 提交读段帧。
**内部各占多少，要靠函数级埋点（见 §4）。**

### 2.4 性能目标（现场重测，别引用历史数字）

本机就是 **i5-13500H / 16 线程**（与历史基线同一颗），2026-10-13 实测 `tools/run_cpu_benchmark.py`：
C(-O3+popcount) 每记录 **1T 0.219 / 4T 0.079 / 8T 0.051 / 16T 0.038 ms**。
板端 P16 实测 **0.081426 ms/记录**（全量 8.9486 s）。
→ 对单核已快 2.7×、对 4 线程基本打平、**对 16 线程还慢 2.14×**；用户目标是**打过 CPU**。
⚠️ 该对照**偏向 CPU**：CPU 数只算比对内核，板端数是**端到端**（含 DMA/Voter/协议/固定开销）。引用时两边口径都要写。

### 2.5 已证伪 / 已归档，**不要再走**

1. **「lwIP poll 空等 2,777 ms」** —— 那是 **P12 之前**的固件（P7 评测于 2026-09-11）。当前 `sw/app/main.c` 已是 P12-B 事件驱动。
2. **「删掉 `PIPE_RUN_SLEEP_US=200` 节流」** —— 2026-10-13 已做完整 A/B：三档 200/50/0 的斜率
   `0.079086 / 0.078348 / 0.079057 ms/记录`，**差异 <1%，端到端一点没快**；时间只是从 `[waiting]` 搬进 `[in-state]`。
   `docs/03` P13「不能盲删 200us 节流」已获实测支持。
3. **TX_STREAM 压缩** —— 归档记录里**已尝试四次并放弃**：真正约束是硬件处理每帧的墙钟时间，
   原设计是**时间节拍器**而非容量节流器。**不要再从 BD 环容量下手。**
4. **Voter/Decoder 微架构流水线化** —— 板上周期实测：Stage2 644.9 ms、Stage3 0.022 ms，即使归零，端到端提速 <1%。
5. **P32/P64（加 `P_WAYS`）** —— 外推整机 58.7k / 108k LUT，**均超 XC7Z020 的 53.2k**，不是候选。
6. **精确种子索引** —— 实测最佳位置最长连续匹配仅 5~7 nt，16-mer 命中概率 ≈1.5e-05，**在本任务不可用**。
7. **流式阶段批量推进** —— 两次失败（`submitted=640 > ring free=512`，Stage1 停顿约 30 s 直接 FAIL）。

## 3. 已知候选项（**不预设大小，小的也要**）

用户明确指示：**不要在意可优化点的大小，每一点即便很小也要优化。**
底稿 §5 已列 10 条，按面向分成三组：

**A. 上位机 / 协议侧（不占 PL，见效快）**
- 上传与处理**重叠**（流式下发，而不是"全部传完再 POST"）；
- **上传吞吐本身**：目前逐批 ACK 停等（`sw/app/echo.c` 的 `PKT_BATCH` ACK 往返），按估算只有约 2 MB/s，**千兆链路下明显偏低**；
- LDPC 与下一轮**并行**；
- 上位机分片/缓冲/串口采集的零碎开销。

**B. PS 侧（固件）**
- 逐 BD 描述符 `Xil_DCacheFlushRange`（`sw/app/bd_ring.c`）——103616 条记录对应约 103616 次 BD 处理；
- BD 提交/回收的逐条开销；
- lwIP 收包路径（`xemacif_input`）耗时；
- 无睡眠下那 2362 ms 的 `[waiting]`（非状态时间）；
- WM 展开/预载、结果打包与发送。

**C. PL 侧（RTL）**
- Stage1 `S_RUN` **每拍只推进 1 个碱基索引**（`READ_BPS=150` → 150 拍/块）；多碱基并行是主要方向；
- 每块 **18 拍预充填 + 7 拍选优排空**（占 176 拍的 14%）能否与相邻块重叠；
- 提高时钟（**⚠️ 不是免费加速**：WNS 仅 +0.617 ns，最差路径 84.5% 是布线；任何时钟改动都必须以 SHA 逐位不变为门禁）。

## 5. 纪律（照做，不要商量）

**资源独占**：板卡、串口、EDA 三类资源各**同时只允许一个任务**。板卡任务与"编辑它要调用的脚本"**不能重叠**
（历史上这么干过，扫到改到一半的 `run_g3.sh`，看起来像板子坏了）。

**子 Agent 一律走 codex-luna MCP**（`codex_run` / `codex_status`），固定 `gpt-6-luna` + `max`，**不降级**。
成功判据四项全中：`status=completed`、`ok=true`、`exit_code=0`、`turn_completed=true`。
- 每个子 Agent 在 prompt 里指定 **`--agent` 看板短名**；**workspace-write 由执行者自行登记看板，read-only 由 main 代登记**。
- 子 Agent **不做任何 Git 写操作**，也**不派发下一级**。
- **⚠️ 子 Agent 在 codex 沙箱内不要运行 `tools/verify_repo_binding.sh`**（沙箱把 git 目录挂成只读，必然失败白跑）。
- 派发后**立刻挂完工监视**，别靠"等下次说话时顺便查"。

**Git（最高优先级门禁）**：唯一 Git 写入者是 **main**。禁止 `git add -A` / `git add .`；
提交用 `git commit -F <消息文件> -- <显式路径>`；**提交信息禁止 `Co-authored-by` 尾注**；
每次提交后 push，确认 `main...origin/main` 为 `0/0`。

**看板**：动手前 `tools/agent_view.sh start --agent speed ...`，交接前 `done`；禁止手工编辑 `view.md`。

**判据纪律**：任何优化都必须先写下**能变红的判据**再动手（本轮 H1/H2 预登记救过一次——
不然"去掉节流省了 8.5 s 空等"这种话很容易被当成结论）。**失败证据必须保留，不得为全绿放宽门禁。**

**边界声明**：板端耗时若来自客户端打印值或固件 tick，就**不能**说成硬件周期；
`hardware_cycles`/`power_w` 无采集时如实写 `null`，**严禁用墙钟 × 时钟反推周期或用 TDP 估算反推功耗**。

## 6. 验收

一条优化只有在**全部**满足时才算成立：

1. 唯一判据 SHA **逐位不变**（`run_g3.sh` 全量档，`--strict-artifacts`）；
2. 有**同输入、同板、同天**的前后对照（≥3 次，报中位数与离散，不只报最好一次）；
3. **能失败的判据**事先写下，且改坏时确实会红（必要时做一次故障注入自证）；
4. 四档以上规模都测（小档不被固定开销淹没，大档不掩盖真实斜率）；
5. 结论与边界写进 `docs/`（03/05/09 + 对应 benchmark），并**登记到 `docs/09-evidence-ledger.md`**；
6. 已冻结的参考包与既有留证**零污染**。
