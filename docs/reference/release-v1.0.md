## 2. v1.0 包含什么

- **Stage1 P16**：16 路滑窗并行、每拍 2 个碱基（K 写死为 `localparam`，构建期传参通道已全部撤销）；
- **Stage2 差分投票流水化**；
- **片上 LDPC 解码**（`ldpc_decoder_v1_0`）；
- **Stage3 有界墙钟轮询**（2026-10-16 改动：把 `PIPE_DONE_STAGE3` 里的无条件 `usleep(50ms)` 换成按墙钟最多等 50 ms、每 1 ms 轮询 `STATUS.IDLE`；同板 A/B 实测 **−50 ms**）；
- **诊断打印分级静默**（`FW_DIAG_LEVEL` 默认 1：抑制逐状态明细、保留错误与告警，实测 **−367 ms** 且排障能力零损失）。

## 3. 为什么可以把既有证据全部归到 v1.0

v1.0 与今天所有板测所用的固件**是同一份代码**——已用三重核对确认：

| 核对 | 结果 |
| --- | --- |
| bit 逐字节 | v1.0 `81229e23…` **=** 板上运行的那份 |
| ELF strip-debug 后逐字节 | `b967585f…` **=**（两边完全相同） |
| `nm -S` 符号表 | **852 个符号尺寸全同** |
| FSBL strip-debug 后逐字节 | 相同 |

⇒ 以下证据**全部适用于 v1.0**：

- **G3 三层判据**（架构 syndrome 全零 + 系统载荷 SHA 命中 + 裁决 PASS）；
- **8 h 长稳**：1750 轮全过、0 失败、1750 次畸变注入全恢复、墙钟 8.005 h；
- **v2 数据集 @ 出厂门限 `score_min=67`**：26 通过 / 16 安全失败 / **0 例静默给出错误字节**；
- **多载荷泛化回归**：6/7，与文档基线逐项一致（唯一 FAIL 是已知的高熵边界）；
- **SD 卡冷启动**：板子自行启动、**全程无 JTAG 写操作**下通过三层判据。

## 6. 边界（不要把 1.0 读成"全都做完了"）

- **QSPI 冷启动未测**（只做了 SD）；SD 那次也**没抓到 FSBL 启动日志**，"从 SD 启动"是由
  「拨码=SD + QSPI 从未写过 + 全程无 JTAG 写操作」推出的；
- **功耗未测**（无仪器）。历史海报上那个"功耗 <2.5 W"**我们从未测过，不得沿用**；
- **工具版本是 Vivado/Vitis 2022.2**，而指南要求 2026.1（推荐）或 2025.2，
  **"用其他版本需在报告中说明并保证脚本可复现"** —— 这一条必须在正式报告里写明；
- v2 的 16 例失败是**真实失败**，以 LDPC 不收敛的形式暴露；**不得写成 42/42 通过**；
- 数据仍是 **in-silico 模拟测序**，非湿实验数据。
