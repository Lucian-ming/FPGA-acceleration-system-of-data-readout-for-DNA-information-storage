## 2. 音画同步

渲染按全局帧号 `f` 出画，`t = f / 30`；每个场景在自己的时间窗内绘制，
场景边界处 0.55 s 的溶接在帧函数内部合成，因此画面与旁白共用同一时间轴。

- 时间轴：`135.735 s = 9 场 / 29 句`（`build/timeline.json`）。
- 渲染日志：`时间轴 135.735 s -> 4072 帧（溶接 0.55 s）`、`静画 135.740 s（差 +0.005 s）`。
- 差 0.005 s 来自容器时间基的取整，落在片尾，不影响任何一句旁白。
- 解码计数：`ffmpeg -progress` 末行 `frame=4072`、`out_time_us=135733333`，与时间轴一致。

## 6. 溶接连续性

在**八个**场景边界上各取相邻三帧（边界前一帧 / 边界帧 / 后一帧，即 `f-1, f, f+1`，
解码到 480×270 灰度），记录相邻帧平均绝对差与三帧最小灰度：

```
 13.019 s f391    0.93 / 0.30   min = 197, 188, 157
 23.855 s f716    0.94 / 0.33   min = 189, 189, 163
 47.498 s f1425   0.38 / 0.24   min = 187, 187, 164
 69.785 s f2094   0.59 / 0.32   min = 187, 188, 157
 81.927 s f2458   1.07 / 0.35   min = 189, 189, 168
100.764 s f3023   1.31 / 0.23   min = 197, 186, 169
109.088 s f3273   1.00 / 0.26   min = 188, 188, 161
125.329 s f3760   1.16 / 0.05   min = 188, 188, 170
```

相邻帧差都在 1.31 个灰度级以内，没有跳变。三帧最小灰度 157–197，是纸底加 10%
淡影，不是空纸（上一版边界帧最小灰度 6~9，随后一帧直接跳到 175，那是硬切）。

这一版同时修掉了出画分支写反的缺陷：`draw_global` 原条件 `i > 0 and (t - start_i) < half`
在 `i` 已按 `t >= start_i` 选出后恒为真，实际只有淡入、没有淡出，切换前最后一帧仍是
满不透明，于是边界处硬切到纸。现拆成两段独立判断——淡入看本场起点后半个窗，淡出看
下一场起点前半个窗，两端在边界帧都保留 `FLOOR = 0.10` 的不透明度，画面不经过纯纸。

每一场都有 0.6–1.6 s 的静止尾巴，淡出段把上一场锁在它的最后一帧上，切断处看不到运动。
