## 2. 音画同步

渲染按全局帧号 `f` 出画，`t = f / 30`；每个场景在自己的时间窗内绘制，
场景边界处 0.55 s 的溶接在帧函数内部合成，因此画面与旁白共用同一时间轴。

- 渲染日志：`时间轴 249.223 s -> 7477 帧（溶接 0.55 s）`
- 拼完实测：`静画 249.240 s（时间轴 249.223 s，差 +0.017 s）`
- 差 0.017 s ≈ 0.5 帧，来自 7477 / 30 的取整，落在片尾，不影响任何一句旁白。
- 解码计数：`frame= 7477`，与时间轴一致。

## 6. 溶接连续性

在**八个**场景边界上各取相邻三帧（边界前一帧 / 边界帧 / 后一帧，即 `f-1, f, f+1`，
解码到 480×270 灰度），记录相邻帧平均绝对差与三帧最小灰度：

```
18.770 s  f563   0.04 / 1.09   min = 197, 197, 175
37.740 s  f1132  0.04 / 1.04   min = 189, 189, 178
80.210 s  f2406  0.02 / 0.48   min = 189, 189, 173
117.620 s f3529  0.57 / 0.29   min = 187, 189, 162
145.440 s f4363  0.03 / 1.06   min = 189, 189, 179
186.700 s f5601  0.01 / 1.50   min = 197, 197, 173
211.300 s f6339  0.04 / 1.10   min = 188, 188, 174
238.580 s f7157  0.05 / 1.15   min = 189, 189, 181
```

相邻帧差都在 1.5 个灰度级以内，没有跳变。边界帧的最小灰度 187–197，是纸底加 10%
淡影，不是空纸（上一版边界帧最小灰度 6~9，随后一帧直接跳到 175，那是硬切）。

这一版同时修掉了出画分支写反的缺陷：`draw_global` 原条件 `i > 0 and (t - start_i) < half`
在 `i` 已按 `t >= start_i` 选出后恒为真，实际只有淡入、没有淡出，切换前最后一帧仍是
满不透明，于是边界处硬切到纸。现拆成两段独立判断——淡入看本场起点后半个窗，淡出看
下一场起点前半个窗，两端在边界帧都保留 `FLOOR = 0.10` 的不透明度，画面不经过纯纸。

每一场都有 0.6–1.6 s 的静止尾巴，淡出段把上一场锁在它的最后一帧上，切断处看不到运动。

## 9. 逐帧审计（12 路并行，502 帧）

成片时间轴上每 0.5 s 抽一帧，共 **502 帧**（`build/qa/frames/`，索引 `build/qa/index.txt`），
按场景切成 12 段，分派给 12 个只读 codex 子 agent，对照 `build/qa/facts.md` 逐帧检查
（数字与口径、术语、跨帧叠字、版面越界、旁白与画面是否重复）。判据与报告格式见
`build/qa/REVIEW-BRIEF.md`。

主会话对每条意见都回原始依据复核，**不采信未给出处或与源码相反的意见**（例如审计称
「饱和钳位」「50 轮上限」「正反向各一遍」无依据，均被 RTL / CLI 源码驳回，见 §8）。
确认的缺陷全部在 `src/scenes/*.py` 源头修掉，然后整片重渲。
