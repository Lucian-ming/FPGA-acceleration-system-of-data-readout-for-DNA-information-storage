## 2. 音画同步

渲染按全局帧号 `f` 出画，`t = f / 30`；每个场景在自己的时间窗内绘制，
场景边界处 0.55 s 的溶接在帧函数内部合成，因此画面与旁白共用同一时间轴。

- 渲染日志：`时间轴 249.223 s -> 7477 帧（溶接 0.55 s）`
- 拼完实测：`静画 249.240 s（时间轴 249.223 s，差 +0.017 s）`
- 差 0.017 s ≈ 0.5 帧，来自 7477 / 30 的取整，落在片尾，不影响任何一句旁白。
- 解码计数：`frame= 7477`，与时间轴一致。

## 3. 音频电平

命令：`ffmpeg -i … -map 0:a -af volumedetect -f null -`

```
mean_volume: -19.5 dB
max_volume:  -1.5 dB
```

峰值 −1.5 dB，无削波。铺底音乐由旁白包络压低后再混入（这是合成参数，不是电平测量的结论）。

## 6. 溶接连续性

在三个场景边界上取相邻三帧（边界前一帧 / 边界帧 / 后一帧，即 `f-1, f, f+1`，
解码到 480×270 灰度），相邻帧平均绝对差与最小灰度：

```
18.768 s  f563   0.88 / 1.04   min = 98, 116, 100
37.739 s  f1132  0.91 / 0.87   min = 20,  19,  17
145.441 s f4363  0.91 / 0.91   min = 17,  17,  18
```

相邻帧差都在 1 个灰度级以内，没有跳变；三帧的最小灰度都不为 0，没有黑场。
每一场都有 0.6–1.6 s 的静止尾巴，溶接手柄不会露出被切断的运动。
