## 2. 音画同步

渲染按全局帧号 `f` 出画，`t = f / 30`，总帧数 `round(260.317 × 30) = 7810`，
每个场景在自己的时间窗内绘制，场景边界处的 0.55 s 溶接在帧函数内部合成。

- 渲染日志：`时间轴 260.317 s -> 7810 帧（溶接 0.55 s）`
- 拼完实测：`静画 260.340 s（时间轴 260.317 s，差 +0.023 s）`
- 差 0.023 s ≈ 0.7 帧，来自 7810 / 30 的取整，出现在片尾黑场，不影响任何一句旁白。

> 历史缺陷（已修）：上一版按「场景体 + 单独溶接片」拼接，8 个边界各吃掉 16 帧，
> 成片只有 255.01 s，画面比旁白和字幕快 5.3 s。改成全局帧号渲染后长度对齐。

## 3. 音频电平


峰值 −1.4 dB，没有削波余量不足的问题；铺底音乐由旁白包络压到 55%，没有盖住人声
（这一条是设计参数，不是电平测量的结论）。

## 6. 溶接连续性

在 s1→s2 边界（13.334 s）前后取三帧，灰度平均绝对差：

```
13.20 -> 13.35   mean|Δ| = 3.20
13.35 -> 13.50   mean|Δ| = 2.16
```

没有整帧黑场或跳变（同时检查了三帧的最小灰度值，无全黑帧）。每一场都以 0.6–1.6 s
的静止尾巴收尾，所以 ±0.275 s 的溶接手柄不会露出被切断的运动。
