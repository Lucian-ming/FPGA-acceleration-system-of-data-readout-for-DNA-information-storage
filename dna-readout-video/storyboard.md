# 分镜表

135.74 s / 4,072 帧 / 9 场 / 29 句 / 30 fps / 1920×1080。所有画面由代码逐帧生成（`src/scenes/s*.py`），
每帧只依赖绝对时间 `t`，因此任意时刻都可以单独复现。

本片只承担原理讲解。比赛总时长三分钟，剩下 ≈44 s 留给实拍演示，两段拼起来仍在 180 s 以内。

**运动原则**：一场只有一个主动作。背景的双螺旋、颗粒与光晕是常驻的慢速底层运动，
不算主动作；字幕、旁白、画面三者的时间都以 `build/timeline.json` 为准。

**关于溶接**：场景之间 0.55 s 中心溶接，前后各 0.275 s，在帧函数内部合成，
不占用时间轴——所以成片长度等于旁白时间轴，误差 +0.005 s。

**读法**：下表「时段」是旁白第几句的起止（`lines[i].start` → `start + dur`），
即该镜头负责承载的那句话；画面在该句开始前后 0.2–0.4 s 内到位，句子说完时画面已静止。

## 版式与字体

- 画布 1920×1080，安全区左右各 112 px；页码 `NN / 09` 固定右下。
- 正文最小 24 px（1080p 下），场景标题 54 px 衬线（`Noto Serif CJK SC`），收束大字 54–62 px；
  字幕 34 px（`subtitles.ass`，墨色字 + 奶油描边，与纸面底同向）。
- 设计语言：暖白纸面 + 墨色字 + 单一朱红强调（印刷品 / 编辑部），不做发光与霓虹。
  颜色仍然承担标签语义：一级 = 靛蓝（`S1C`），二级 = 松绿（`S2C`），三级 = 赭黄（`S3C`），
  LDPC = 紫（`LDC`），通过 = 绿（`OKC`），异常 / 拒收 = 砖红（`WARNC`）。
- 不单靠颜色区分：`PASS` / `SAFE_NOCONV` 同时用文字标出。
- 旁白不复述画面：画面给名词与数字，旁白给这些名词之间的关系、代价与理由。
