# LC50 双缓冲原型正式测量结果（2026-10-16）

承接 `logs/dev/dbuf-prototype.md`（LC6 冒烟）与 `logs/dev/stage1-overlap-study.md`（可行性推断）。
本次是**离线仿真**，不占板子、不动生产 RTL。

命令与产物：`logs/iverilog/dbuf-proto-lc50/`（`run.log` / `tb_dbuf`），
配置 `LC=50 BATCH=64 BATCHES=3`（生产几何）。

## 1. 功能：通过

```
[PROTO SUMMARY] PASS: 192 records bit-exact cw/pos/score; 3 consecutive batches; res_full backpressure observed
```

192/192 条 `cw/pos/score` 与单缓冲参考核**逐位一致**；连续 3 批；`res_full` 背压确实施加
（原型 29,107 个阻塞周期 vs 参考 29,063）。

## 2. 周期：省下理论上限的 78.4%

| | 3 批总跨度（拍） |
| --- | ---: |
| 单缓冲参考核（串行跑 3 批） | **922,193** |
| 双缓冲原型（流水跑 3 批） | **786,675** |
| 差 | **135,518** |

参考核逐批：307,402 / 307,387 / 307,401（±8 拍，非常稳）。

**折算**：135,518 / 3 = **45,172.7 拍/批** = **0.4517 ms/批**（100 MHz）。
× **1,619 批** ⇒ **≈ 731.4 ms**。

对照理论上限：`S_LOAD_R` + `S_EMIT*` = 每批 57,600 拍，3 批 172,800 拍；
**135,518 / 172,800 = 78.4%**，与 `731.4 / 932.5 = 78.4%` 两个算法互相印证。

⇒ **约 731 ms 的隐藏量是真的**（占当前端到端 5,098 ms 的 **14.3%**），
但**只隐藏了装载/发放服务的 78.4%**，不是全部。

## 3. ⚠️ 一个必须先说清的坑：TB 的 `hidden_*` 计数器少算

TB 打印的

```
[PROTO BATCH] batch=0 ... hidden_load_in_run=22977 hidden_emit_in_run=0
[PROTO BATCH] batch=1 ... hidden_load_in_run=22986 hidden_emit_in_run=23003
[PROTO BATCH] batch=2 ... hidden_load_in_run=0     hidden_emit_in_run=22988
```

三项非零值之和只有 **91,954 拍**，而总跨度差是 **135,518 拍**——**差 43,564 拍**。

核过 TB 源码：那两个计数器只把「装载器/发放器**服务状态与 `S_RUN` 同拍**」的周期记进去，
而实际省下的还包括与 `S_PREFILL`/`S_INITC` 等**其它状态并行**的周期。
⇒ **收益要用「原型跨度 − 单缓冲跨度」这个总量，不能用那两个计数器**；
计数器只是局部分解。本页所有数字都取自跨度。

## 4. 资源代价：可忽略

读段位平面 `PLANE_BANK_DEPTH = ceil(150/2) = 75`、每项 64 位（lo/hi 各一份）：

| | 容量 |
| --- | ---: |
| 生产核（单 bank） | 9,600 bit ≈ 9.4 Kb |
| 原型（`[0:1]` 双 bank） | 19,200 bit ≈ 18.8 Kb |
| 增量 | 9,600 bit ≈ **+0.26 个 RAMB36**（实际大概率 +1） |

发布候选现用 RAMB36 **89/140**。⇒ **放的下的问题不存在**。

## 5. ⚠️ 真正的闸门是时序，不是资源

发布候选 **WNS +0.411 ns / WHS 只有 +0.021 ns**。原型新增 bank 选择、第二套地址/元数据寄存器，
会改变短路径与布线。**周期数说明不了 hold**，必须以**整机布局布线后**的 setup/hold 报告为准。

⇒ 已按此起一个**非生产集成包**的整机 build（把原型体并入 IP 源位、只换 module 名），
只为回答「WHS 还剩多少、失败端点几个」。结果见本目录同批记录。

## 6. 本页没证明什么

- **不是**生产实现：原型未并入生产 IP，未上板，没有板端 A/B。
- 3 批 ≠ 1,619 批：稳态每批隐藏量稳（22,977 / 22,986 / 23,003 / 22,988），
  支持等斜率外推，但**外推到 1,619 批仍是外推**。
- 没有功耗、没有 DRC、没有 bitstream。
- 资源与周期的数字都来自仿真/估算，**不能当作"已实现"**。
